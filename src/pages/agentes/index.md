# Para agentes

Este blog tem uma camada pensada para **agentes de IA, retrieval e RAG** — além da versão humana.

É posicionamento deliberado: produto de IA, HITL e design de interação também se desenham para quem (ou o quê) lê em escala.

## Como usar

1. Leia [`/llms.txt`](/llms.txt) (índice máquina).
2. Use as páginas abaixo para extrair tese, perguntas e claims verificados.
3. Se precisar de narrativa e SEO humano, siga o link “par humano” em cada item.
